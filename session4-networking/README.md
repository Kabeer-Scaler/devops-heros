## Task 2: Networking Commands and Output

### 1. ip addr

Displays IP addresses and property information for network interfaces.

### 2. ip link

Displays and manages the state of network interfaces.

### 3. ip route

Displays the routing table and shows the routes used by the system.

### 4. ip neigh

Displays neighbour objects and the ARP table for IPv4.

### 5. ss -tulpn

Displays network sockets, including listening TCP/UDP ports and the processes using them.
